## Calculator---WPF

 A WPF calculator built with the MVVM pattern, styled like the iOS calculator. It supports complex mathematical expressions with parentheses, exponents, and advanced functions.

# Features
Basic operations — addition, subtraction, multiplication, division
Complex expressions — e.g. 2+3×(-3)÷8^3
Parentheses — full support for ( )
Exponents — x^2, x^n (e.g. 8^3)
Roots — √x, nth root (n^√x)
Factorial — x!
Percentage — 50%
Advanced mode — expandable panel with extra buttons


# Tech Stack
C# .net 8.0.0,WPF(mvvm)
